Widget Elementor con menu hamburger per mobile.

== Description ==

* Voci lette da un menu di WordPress (Aspetto → Menu) o da una posizione del tema, con sottomenu su più livelli.
* Voci extra dal widget: link, telefono, email, WhatsApp, icone social, testo, pulsante CTA (prima o dopo il menu).
* Apertura del pannello: slide da sinistra, destra o dall'alto, dissolvenza, overlay a schermo intero.
* Icona hamburger animata (X, X a due tempi, X con rotazione, freccia, linea), ingresso delle voci in sequenza.
* Chiusura con overlay, link ed ESC; blocco dello scroll; evidenziazione della pagina corrente.
* Accessibile: aria-expanded, aria-controls, focus trap, navigazione da tastiera, rispetto di "riduci movimento".
* WPML e Polylang: le voci del menu seguono la lingua della pagina.
* CSS e JavaScript (vanilla) caricati solo nelle pagine che usano il widget.

== Installation ==

1. Plugin → Aggiungi nuovo → Carica plugin → scegli lu3g-mobile-menu.zip → Attiva.
2. In Elementor cerca "Menu mobile LU3G" (categoria LU3G) e trascinalo nell'intestazione.
